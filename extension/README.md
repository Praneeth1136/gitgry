# GitGry Chrome Extension

Automated GitHub repository maintenance, hygiene, and scheduled commit manager.

## How to Install in Google Chrome (3 Clicks)

1. Open Google Chrome and navigate to:
   ```
   chrome://extensions/
   ```
2. In the top-right corner, toggle **Developer mode** to **ON**.
3. In the top-left corner, click **Load unpacked**.
4. Select the folder:
   ```
   D:\GitGry\extension
   ```
5. Click the puzzle icon in your Chrome toolbar and pin **GitGry**!

---

## Features
- **Step 1:** Connect with GitHub (One-Click OAuth or Instant Personal Access Token).
- **Step 2:** Select repositories (e.g. `leetCode`).
- **Step 3:** Select daily commit range (e.g. 5–12 commits).
- **Step 4:** Pick scheduled time in IST (e.g. 09:00 AM) and active days.
- **Syncs directly to Cloud**: Commits run 24/7 in the cloud on Render + MongoDB Atlas even when Chrome or your PC is shut down!
